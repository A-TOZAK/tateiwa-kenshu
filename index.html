How to ask

頼み方は3つ

AIに頼むのは、職員室で人に仕事を頼むのと似ています。前提を渡さなければ全然違うものが出てくるし、仕上がりのイメージを見せた頼み方は、見せない頼み方と結果がまるで違います。新しい技術というより、いつもの伝え方です。

1

ほしいものを言葉にする

「何かいい感じに」では、人にもAIにも伝わりません。誰のため・どの場面で・何をしてほしいか。まず自分が言葉にします。

2

前提とイメージを渡す

年間指導計画のPDF、学習指導要領、参考にしたい画像。手元の材料を渡すほど、返ってくるものは教室に近づきます。

3

返ってきたものに言葉を返す

いいなら「ここがいい」、違うなら「ここが違う」。一発で当てようとせず、言葉のキャッチボールで寄せていきます。

打たなくていいです：頼みごとはマイクに向かってしゃべれば十分。「えー」「あー」が混じっても、言い直しても、ちゃんと通じます。タイピングの速さは、AIの上手さと関係ありません。
Image generation

画像生成のコツ

AIの画像生成はまだ不十分です。よく見るとおかしいところがあります。授業では、あえてそこを使うことも考えています。

ここでも頼み方は同じ：わざと突っ込みどころのある絵がほしいなら、そう頼みます。「4年生が間違いを見つけられるように、設備が足りない避難所を描いて」。ほしいものを言葉にできれば、下手なAIも狙いどおりに下手になります。

大きさは先に決める

画像生成でいちばん簡単なのに効くのが、縦横の比率（アスペクト比）を先に伝えることです。使い先が決まれば、比率も決まります。

画像を頼むときの型

この5つを入れると、当たりが早く出ます。順番は自由です。

  • 場面：どこで・だれが・何をしている絵か
  • 画風：水彩・写真ふう・やさしいイラスト など
  • 使い先：スライドの背景・プリントの挿絵 など
  • 比率：16:9／4:3／1:1
  • 文字は入れない：AIは絵の中の文字がまだ苦手。文字はスライド側で乗せる

Gemini Notebook

Gemini Notebook

渡した資料の中だけから答えるAIです。ネット全体から適当に答えないのが良さで、学校の資料を渡せば、学校の言葉で返ってきます。当日は体育を例に、この流れを見てもらいます。

基本のやり方：notebooklm.google.com を先生のGoogleアカウントで開く → 「新規作成」 → PDFやドキュメントを画面にドラッグしてアップロード（これが「ソース」）→ 下の欄に聞きたいことを書く。しゃべって入れてもかまいません。
例

体育「バスケットボール型ゲーム」の準備

実演します
  1. Gemini Notebookに、学校の年間指導計画と文科省の体育資料を渡す
  2. 聞く：「この単元のポイントは？　子どもに持たせたい見通しは？」
  3. 聞く：「学級の人数で試合をするなら、何人対何人のチーム分けがいい？」
  4. 頼む：「4年生に伝わる言葉で、授業でやるバスケのルール説明スライドを作って」
  5. できた下書きをPowerPoint形式で受け取り、Googleスライドで仕上げる
分担はいつもこれです：下書きはAI、仕上げの判断は先生。単元の見通しも、ルールの言い方も、最後に決めるのは教室を知っている人です。

Design

学校でよく見るのはどっちのスライド？

スライドを作る前に、1組だけ見くらべてください。左と右、子どもに届くのはどちらか。そして、職員室でよく生まれているのはどちらか。

→
直しに使ったのは3つの動詞だけ：減らす（1枚に1つ）・大きくする（後ろの席へ）・そろえる（色と位置）。この見た目のルールは資料編に全部まとめてあります。今日AIで作るスライドにも、この3つの動詞をかけてから教室へ持っていってください。

Hands-on

触る時間

ここから25分。3つの題材から1つ選んでください。どれもプロンプト帳の文をコピーして（またはしゃべって）始められます。見て終わる研修にはしません。

A

学級開きのスライド

2学期の初日に

2学期の学級開きで、先生が大切にしてほしいと思っていることを1本のスライドにします。

  1. 2学期、子どもたちに大切にしてほしいことを1つ決める
  2. プロンプト帳「A 学級開きスライドの構成」で、Geminiに構成と言葉の案を出させる
  3. 気に入った構成でスライドを作る。表紙の絵は画像生成で（16:9）
見本があります：外﨑が実際に使う形の「大切にしたいこと」スライドを置いておきます。構成・出す画像・言葉の量の目安に。そのまま差し替えて使ってもらって大丈夫です。
見本をダウンロード（.pptx）
B

授業の導入スライド

2学期最初の単元で

2学期最初の単元の入口に、「あれ？」「なんで？」が起きる1枚を作ります。

  1. 2学期最初の単元を1つ決める
  2. プロンプト帳「B 導入の画像を生成」で、見せたい場面の画像を16:9で生成する
  3. 画像1枚＋問い1つでスライドにする。避難所の例のように「へんなところはない？」型も面白い
C

解説系：難しい資料をやさしく

校務にも

難しい文書や資料を、相手に届く言葉に直します。指導資料を自分用に、配布文書を保護者向けに、単元の資料を子ども向けに。

  1. 手元の「読むのが大変な資料」を1つ選ぶ（PDFかドキュメント）
  2. Gemini Notebookに渡して、プロンプト帳「C 難しい資料をやさしく」の言葉で頼む
  3. 返ってきたまとめを読み、「ここをもっと短く」と言葉を返して仕上げる
→

となりの先生と見せ合い

30秒ずつ
  1. 作ったものを30秒だけ見せる
  2. 見た人はひとこと：「これで、子ども（相手）は何を考えると思う？」
Prompts

プロンプト帳

コピーしてそのまま使えます。【　】の中だけ、自分の教室の言葉に差し替えてください。全部しゃべって伝えても構いません。そもそもプロンプトとは、AIへの頼みごとの文のことです。何を頼めばいいか分からないときは、まず0番をどうぞ。

0　プロンプトを作るプロンプト（Gemini）
やりたいこと：【学級開きで使うスライドを作りたい】

これを、AIへの頼みごとの文（プロンプト）にしてください。
足りない情報があれば、先に私に質問してください。
できたプロンプトは、そのままコピーして使える形で出してください。
A　学級開きスライドの構成（Gemini）
あなたは小学校の学級経営が得意な先生です。
2学期の学級開きで使うスライドの構成を考えてください。

伝えたいこと：【あいさつは自分から。教室を安心できる場所にしたい】
学年：【4年生】
時間：学活のはじめの【10分】

条件：
・スライドは6枚まで。1枚に伝えることは1つ
・子どもに問いかける枚を1枚入れる
・各スライドの「見出し」「入れる画像のイメージ」「先生がしゃべること」を分けて書く
B　導入の画像を生成（Gemini）
画像を作ってください。

場面：【朝の川原。増水した川が茶色くにごって流れている】
画風：【写真のようにリアルに】
使い先：授業のスライドの背景
比率：16:9
画像の中に文字は入れないでください。
B'　わざと突っ込みどころのある絵（Gemini）
画像を作ってください。

場面：【体育館に開設された避難所。人が過ごしている】
ねらい：【4年生】が「おかしいところ」を見つける教材にしたいので、
【通路がない・水や毛布が見当たらない・間仕切りがない】など、
設備の足りないようすをわざと入れてください。
画風：やさしいイラスト
比率：16:9
画像の中に文字は入れないでください。
C　難しい資料をやさしく（Gemini Notebook／Gemini）
渡した資料を、【保護者】に伝わる言葉でまとめ直してください。

条件：
・A4半分くらいの長さ
・専門用語はふつうの言葉に言いかえる。言いかえられないものは（　）で短く説明
・「結局なにをすればいいか」を最後に3つの箇条書きで
D　単元の見通しを聞く（Gemini Notebook）
渡した年間指導計画と資料をもとに教えてください。

・【体育「バスケットボール型ゲーム」】の単元で、いちばん大事にすることは何ですか
・【28】人の学級で試合をするなら、何人対何人のチーム分けがよいですか。理由も
・第1時で子どもに持たせたい「見通し」を、子どもに話す言葉で書いてください
